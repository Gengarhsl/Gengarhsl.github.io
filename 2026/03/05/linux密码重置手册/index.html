五、为什么可以重置 root 密码？

核心原因：

只要满足以下条件：

  • 能访问服务器控制台
  • 能修改 GRUB 启动项
  • 没有设置 GRUB 密码

就可以重置 root 密码。

六、生产环境安全防护

为了防止非法修改 root 密码，需要采取安全措施。

1 设置 GRUB 密码

这样进入 GRUB 编辑界面需要密码。

2 禁止外部设备启动

在 BIOS 中：

  • 禁止 U 盘启动
  • 禁止光驱启动

3 设置 BIOS 密码

防止攻击者修改启动顺序。

4 使用磁盘加密

Linux 推荐使用：

LUKS

磁盘加密后：

  • 没有密码无法挂载磁盘
  • 无法修改系统文件
  • 无法重置 root 密码

5 机房物理安全

服务器安全原则：

如果攻击者拥有：

  • 服务器物理访问权限
  • 控制台权限

任何系统都可能被破解。

七、云服务器为什么不能这样操作

在云环境中，例如：

  • Amazon Web Services
  • Alibaba Cloud
  • Tencent Cloud

用户通常无法：

  • 修改 GRUB
  • 控制启动过程
  • 直接访问磁盘

因此只能通过云平台提供的 重置密码功能。
