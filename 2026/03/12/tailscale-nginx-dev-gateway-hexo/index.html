Tailscale + Nginx Dev Gateway 部署指南

本文介绍如何在公司服务器上部署 Nginx Dev Gateway，使远程开发者通过
Tailscale VPN 接入公司微服务环境，并通过 Nacos 注册中心 与
Gateway 正常通信，同时不影响内网用户。

目标：

  • 内网服务正常使用
  • 远程开发服务可接入微服务体系
  • 不需要修改每个服务配置
  • 不需要关闭 SELinux

十一、总结

通过 Tailscale + Nginx Dev Gateway 可以实现：

  • 远程开发接入公司微服务环境
  • 内网服务完全不受影响
  • 不需要修改每个服务配置
  • SELinux 保持开启

该方案适合：

  • Spring Cloud
  • Nacos
