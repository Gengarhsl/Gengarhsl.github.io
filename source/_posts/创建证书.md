# 🧾 自签 RootCA + 签发带多个 IP 的服务证书 + 导入信任库 全流程笔记

## 📁 目录结构建议

```
certs/
├── rootca/
│   ├── rootca-key.pem
│   ├── rootca-cert.pem
│   └── rootca.p12
├── gateway/
│   ├── prodgateway-key.pem
│   ├── prodgateway.csr
│   ├── prodgateway-cert.pem
│   └── prodgateway.p12
└── openssl-san.cnf
```

---

## 1️⃣ 创建 RootCA 根证书（如已存在可跳过）

```bash
# 生成 RootCA 私钥
openssl genrsa -out rootca-key.pem 2048

# 生成 RootCA 证书
openssl req -x509 -new -nodes -key rootca-key.pem -sha256 -days 3650 -out rootca-cert.pem -subj "/C=CN/ST=State/L=City/O=Organization/OU=OrgUnit/CN=rootca"

# 可选：导出为 truststore.p12
openssl pkcs12 -export -out rootca.p12 -inkey rootca-key.pem -in rootca-cert.pem -name rootca
```

---

## 2️⃣ 创建包含多个 IP 的 OpenSSL 配置文件

新建文件 `openssl-san.cnf`，内容如下：

```ini
[req]
distinguished_name = req_distinguished_name
req_extensions = v3_req
prompt = no

[req_distinguished_name]
C = CN
ST = State
L = City
O = Organization
OU = OrgUnit
CN = prodgateway.example.com

[v3_req]
keyUsage = keyEncipherment, dataEncipherment, digitalSignature
extendedKeyUsage = serverAuth
subjectAltName = @alt_names

[alt_names]
IP.1 = 192.168.3.166
IP.2 = 192.168.3.197
IP.3 = 192.168.3.201
IP.4 = 113.250.177.98
```

---

## 3️⃣ 生成服务证书和私钥（prodgateway）

```bash
# 生成私钥
openssl genrsa -out prodgateway-key.pem 2048

# 生成 CSR（证书签署请求）
openssl req -new -key prodgateway-key.pem -out prodgateway.csr -config openssl-san.cnf
```

---

## 4️⃣ 使用 rootca 签署 prodgateway 证书

```bash
openssl x509 -req -in prodgateway.csr -CA rootca-cert.pem -CAkey rootca-key.pem -CAcreateserial -out prodgateway-cert.pem -days 365 -sha256 -extensions v3_req -extfile openssl-san.cnf
```

📌 `-CAcreateserial` 会自动生成 `rootca-cert.srl` 文件。

---

## 5️⃣ 可选：打包为 `.p12` 格式（供 Java 使用或导入 Truststore）

```bash
openssl pkcs12 -export -in prodgateway-cert.pem -inkey prodgateway-key.pem -out prodgateway.p12 -name prodgateway -CAfile rootca-cert.pem -caname rootca
```

---

## 6️⃣ 导入 `prodgateway.p12` 到现有 Truststore

```bash
keytool -importkeystore -deststorepass 123456 -destkeystore truststore.p12 -srckeystore prodgateway.p12 -srcstoretype PKCS12 -srcstorepass 123456
```

> - `truststore.p12` 是你已有的信任库  
> - 可用以下命令查看条目：
> ```bash
> keytool -list -keystore truststore.p12 -storepass 123456
> ```

---

## 7️⃣ 验证 SAN 是否包含 IP

```bash
openssl x509 -in prodgateway-cert.pem -noout -text | findstr /C:"Subject Alternative Name"
```

应看到：

```
X509v3 Subject Alternative Name:
    IP Address:192.168.3.166, IP Address:192.168.3.197, ...
```

---

## ✅ 最终用途

- **Nginx / 前端服务** 可配置 `prodgateway-cert.pem + prodgateway-key.pem`
- **浏览器不会再报 ERR_CERT_AUTHORITY_INVALID**
- **HTTPS API 请求能通过 Truststore 验证**
